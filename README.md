# 遠大售票搶票機器人

此為專門針對遠大售票的搶票機器人，在政府不強力打擊黃牛下，身為 k-pop 粉（有看 VIVIZ, GFriend, IZNA, TripleS, BLACKPINK, ITZY, Stayc, NMIXX, formis_9, kep1er, ive, le sserafim, gyubin, IU, tws, stray kids, txt, JYP），只能透過自救的方式，打不贏就跟進，讓所有跟我一樣搶不到票又沒有門路的粉絲可以跟黃牛有相同的起跑線。

## 使用方式

### 前置作業

若電腦未安裝 python3，請先進行安裝

Windows: [下載連結](https://www.python.org/ftp/python/3.14.3/python-3.14.3-amd64.exe)

MacOS: [下載連結](https://www.python.org/ftp/python/3.14.3/python-3.14.3-macos11.pkg)

### 中置作業

點選綠色 code 按鈕，再點選下面的 Download ZIP，下載後解壓縮。

解壓縮後，Windows: 點上面像網址列的地方，把字都刪除，打上 cmd，MacOS: 在資料夾上右鍵，點選 新增位於檔案夾的終端機視窗

接下來輸入指令：
```
python3 -m pip install -r requirementS.txt 
playwrite install
```

### 開始使用

在終端機裡輸入
```
python3 app.py
```

接下來打開瀏覽器（Chrome, Opera 或任何你習慣的），在網址列輸入 ```127.0.0.1:5001```
